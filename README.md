# Avaliação Anual de Colaboradores — Monte do Pasto

Ferramenta online para criação de fichas de avaliação anual de colaboradores,
desenvolvida para o Monte do Pasto.

A aplicação permite:
- Diferenciar funções **Operacionais / Campo** e **Administrativas**
- Atribuir classificações de **1 a 5**
- Inserir comentários livres
- Gerar automaticamente uma ficha de avaliação profissional em português de Portugal

## Tecnologias
- HTML
- CSS
- JavaScript
- GitHub Pages

## Utilização
1. Preencher os dados do colaborador
2. Selecionar o tipo de função
3. Atribuir as classificações
4. Inserir os comentários
5. Gerar a ficha de avaliação

A ficha pode ser copiada, impressa ou guardada em PDF.
